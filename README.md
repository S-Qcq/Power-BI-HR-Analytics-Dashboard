# Power-BI-HR-Analytics-Dashboard

https://www.youtube.com/watch?v=0BKlUySopU4&list=PLwIcJx1aSL1SeTJgPbFgf1V-5CfsV4l1l

create dynamic measures, and build a simple, visually cohesive dashboard.
